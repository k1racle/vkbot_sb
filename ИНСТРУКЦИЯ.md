# Инструкция по работе с «VK Бот»

Вход в панель: [vkbot.it-sarkisian.ru/admin](https://vkbot.it-sarkisian.ru/admin). Используйте логин и пароль, которые задали при установке.

Для обычной работы — менять сообщения, акции и диалоги — заходить в Portainer не нужно.

## 1. Как работает бот

У бота два независимых направления.

**Промокоды за комментарии.** Человек оставляет комментарий, бот проверяет условия кампании. Дальше возможны два режима: сразу отправить **личное сообщение от сообщества** или ответить под комментарием к посту и пригласить за подарком в чат. Сам промокод и файл всегда отправляются в личку. Это настраивается в разделе «Кампании».

**Переписка с клиентом.** Человек пишет в личные сообщения сообщества. Бот показывает меню, задаёт вопросы, отвечает по настроенному сценарию или вызывает менеджера. Это настраивается в разделах «Сценарии» и «Общение».

Можно использовать оба направления одновременно или только одно. Для выдачи промокодов за комментарии не нужно публиковать сценарий общения.

Дополнительно в «Клиентах» есть база контактов, а в «Рассылках» — отправка новостей и предложений тем, кому бот уже писал. Рассылки запускаются вами отдельно и не требуют комментария от клиента.

Важно: подписка на сообщество и разрешение получать от него сообщения — разные вещи. Для получения промокода в личку клиент должен разрешить сообщения сообщества.

## 2. Кампании — промокоды за комментарии

Кампания — это акция для определённого поста или общая акция для всех постов и видео сообщества. У каждой кампании свои сообщение, промокод, вложение и условия.

### Создать кампанию

Откройте «Кампании» → «Новая кампания» и заполните поля:

- **Название** — для себя, например «Скидка за комментарий — сентябрь».
- **ID поста** — оставьте пустым для общей кампании на все посты и видео. Для одного поста укажите его номер: для ссылки `https://vk.ru/wall-240572018_594` нужно **594**. Число `240572018` — это ID сообщества, в этом поле оно не нужно. Для режима «все публикации» не вводите `0`, а просто очистите поле.
- **Промокод** — например `SARKISIAN10`.
- **Ссылка на магазин** — например `https://sarkisianbrand.ru/`.
- **Текст сообщения** — то, что клиент получит в личку.

Пример сообщения:

```text
Привет, {first_name}! Спасибо за комментарий 💚

Ваш промокод на скидку: {promo_code}

Перейти в магазин: {shop_url}
```

Бот сам заменит:

- `{first_name}` или `{user_name}` — на имя клиента;
- `{promo_code}` — на промокод этой кампании;
- `{shop_url}` — на ссылку этой кампании.

Фигурные скобки нужно оставить. Вручную вписывать имя каждого клиента не требуется.

Сам промокод предварительно создайте в своём магазине. Бот только отправляет указанный код — скидку на сайте он не создаёт.

### Прикрепить файл

В поле загрузки выберите файл с компьютера и сохраните кампанию.

Поддерживаются изображения, видео, аудио и документы. Размер — до **50 МБ**. Изображения отправляются как фотографии, видео и аудио — как файлы, не как голосовые сообщения.

Чтобы заменить вложение, выберите новый файл и сохраните кампанию. Чтобы убрать его из ответа, отметьте «Убрать вложение» и сохраните изменения.

### Пригласить в чат ответом на комментарий

Этот режим подходит, если человек ещё не разрешил сообщения сообщества. Ему не нужно писать заранее, до участия в акции.

1. Откройте нужную кампанию.
2. В поле **«Способ выдачи»** выберите **«Пригласить в чат ответом на комментарий»**.
3. Отредактируйте готовые варианты приглашения или добавьте свои кнопкой «Добавить вариант». Можно сохранить от 1 до 10 текстов, до 2000 символов каждый. Бот случайно выбирает один текст для приглашения; иногда варианты могут повторяться. Разные тексты не обходят ограничения VK на частые ответы.
4. В каждом варианте оставьте **`{chat_url}`** — вместо неё бот вставит ссылку из раздела **«Настройки» → «Ссылка на чат»**. Например, укажите там `https://vk.me/sarkisian.brand` и нажмите «Сохранить настройки». Остальные переменные из личного сообщения здесь не подставляются.
5. Сохраните кампанию.

Ссылка общая для всех приглашений. Её можно менять в админке без ENV и перезапуска бота; рядом с вариантами приглашения есть переход **«Изменить ссылку на чат»**. Если очистить поле и сохранить, бот снова будет использовать автоматический адрес `https://vk.me/club<ID сообщества>`. Новый адрес действует только для следующих приглашений: старые комментарии не переписываются и ожидающие подарки не сбрасываются.

Важно: адрес должен открывать сообщения сообщества, к которому подключён бот. Одна смена ссылки не подключит другое сообщество и не перенесёт туда подарки. При запуске другого проекта настройте для него сообщество, ключ VK и Callback API отдельно, а затем задайте его ссылку в админке.

Пример приглашения:

```text
Спасибо за комментарий и активность 💚 Мы приготовили для вас подарок!
Заберите его в сообщениях: {chat_url}
Нажмите «Начать» или напишите «Подарок».
```

Что увидит клиент:

- Под подходящим комментарием появится ответ сообщества со ссылкой.
- Клиент перейдёт в чат и нажмёт «Начать», если VK показывает эту кнопку. Если её нет, отправит слово **«Подарок»**.
- Бот ещё раз проверит подписку, активность кампании и предыдущие выдачи, затем пришлёт её личное сообщение с промокодом и вложением. **Один переход по ссылке не даёт разрешения писать человеку.**

Бот помнит ожидающий подарок после перезапуска. Повторные комментарии одного человека в этой кампании не создают новые приглашения, пока подарок ожидает получения — даже если разрешена повторная выдача. Если подарок уже получен, действует настройка «Один промокод клиенту». Другой человек не сможет получить ваш подарок по публичной ссылке: нужен его собственный подходящий комментарий.

В режиме приглашения **человеку не обязательно быть подписанным в момент комментария**. Если он нажал «Начать» или отправил «Подарок», но ещё не подписан, бот ответит: «Ваш подарок уже ждёт. Чтобы получить его, подпишитесь на сообщество». Под сообщением будут кнопки «Подписаться на сообщество» (открывает его страницу) и «Проверить подписку».

После подписки бот **автоматически отправит промокод**, когда получит от VK событие о вступлении и подтвердит подписку. Дополнительное сообщение от клиента не требуется. На стороне VK необходимо включить событие **`group_join` — «Вступление в сообщество»**: «Управление» → «Работа с API» → «Callback API» → «Типы событий». Если событие выключено, не пришло или задерживается, клиент может нажать «Проверить подписку» либо написать «Подарок». Бот проверит подписку заново. Заявка на вступление в закрытое сообщество ещё не считается подпиской: нужно дождаться её одобрения.

Автоматическая выдача работает только для ожидающего подарка, который человек **сам запросил в чате**. Просто вступившим или открывшим ссылку людям бот не пишет. Перед отправкой он также проверяет, что личные сообщения сообщества всё ещё разрешены. Нажатие «Начать» без подходящего комментария не создаёт промокод — продолжает работать обычный сценарий общения.

Если подарков от разных кампаний несколько, выдаётся один за раз, затем появляется кнопка «Следующий подарок». Чтобы вернуться к обычному сценарию, нужно написать «меню». Запрос подарка и автоматическая выдача не сбрасывают текущий шаг сценария и не снимают закрепление за менеджером.

Выдача ожидающих подарков работает независимо от переключателя «Отвечать на личные сообщения» и не требует опубликованного сценария. Чтобы остановить выдачу конкретной акции, приостановите кампанию. Запрошенный во время её отключения подарок отменяется; после включения нужен новый подходящий комментарий. Уже созданные приглашения не отменяются просто от смены способа выдачи на прямой.

**Настройки VK:** сообщество должно принимать сообщения; в Callback API включите `wall_reply_new`, `message_new` и `group_join`. Ключу сообщества нужен доступ к стене для ответа и к сообщениям для выдачи подарка. VK может отказать, например, если комментарии закрыты или ссылки запрещены. Ошибка видна в «Статистике». Повторные публичные ответы автоматически не отправляются; если приглашение не удалось, заработанный подарок всё равно можно запросить словом «Подарок» в чате. При ошибке личной отправки тоже можно повторить «Подарок».

**Ограничение для видео:** с текущим ключом сообщества этот режим отвечает только под постами, включая посты с видео. Комментарии непосредственно под видео и клипами в режиме приглашения пропускаются с отдельным статусом. Для них используйте режим прямой отправки; разрешение на личные сообщения тогда должно быть получено заранее. Это ограничение [метода VK для ответов под видео](https://github.com/VKCOM/vk-api-schema/blob/master/video/methods.json).

### Настроить условия

**Минимальная длина комментария.** Например, `10` означает: комментарии короче 10 символов не подходят для получения промокода.

**Стоп-слова.** Вводите по одному на строку. Если комментарий содержит любое из них, бот его пропустит. Большие и маленькие буквы не различаются. Учитывается и совпадение внутри слова, поэтому слишком короткие стоп-слова лучше не использовать.

**Один промокод клиенту в этой кампании.** Если включено, повторные комментарии одного человека не приводят к повторной выдаче.

Защита действует отдельно для каждой кампании. В общей кампании она охватывает все посты и видео: комментарий к другой публикации не даёт повторный промокод. Получить промокод другой кампании человек сможет. Выдача через диалог тоже учитывается. Изменение текста, промокода или ID поста в той же кампании не сбрасывает сведения о предыдущей выдаче.

**Активна.** Включает кампанию.

Подписка на сообщество проверяется автоматически.

После настройки нажмите **«Сохранить кампанию»**. Изменения кампании начинают действовать без отдельной публикации.

### Переключаться между кампаниями

Выбирайте нужную кампанию в списке слева. Справа будут настройки только выбранной кампании.

Одновременно могут работать несколько кампаний для разных постов и одна общая кампания. В списке общая кампания помечена «Все публикации».

Правила выбора кампании:

- Если для поста есть отдельная кампания, используется она.
- Если отдельная кампания приостановлена, по этому посту ничего не выдаётся — общая её не заменяет.
- Если отдельной кампании нет, используется общая.
- Для комментариев к самому видео используется общая кампания. Номер видео не нужно вводить в поле «ID поста».
- Если подходящей кампании нет или она выключена, комментарий пропускается.

### Видео и короткие видео (клипы)

Для комментариев к видео включите в настройках сообщества VK: «Управление» → «Работа с API» → «Callback API» → «Типы событий» → новый комментарий к видео (**`video_comment_new`**). Событие комментариев на стене **`wall_reply_new`** оставьте включённым.

Общая кампания обрабатывает новые комментарии под видео, принадлежащими вашему сообществу. Комментарий под постом с прикреплённым видео и комментарий под самим видео — разные события, бот различает их.

С клипами есть ограничение: бот обработает комментарий, **если VK передаст его как событие комментария к видео**. В доступной официальной схеме нет отдельного события для комментариев к клипам, поэтому нельзя обещать их получение для любого клипа. После подключения проверьте новый комментарий под вашим клипом в разделе «Статистика».

Кнопка «Приостановить» временно выключает кампанию. Позже её можно включить снова. Для временной остановки удалять кампанию не нужно.

Бот реагирует на новые комментарии. После изменения настроек для проверки напишите новый комментарий: уже обработанные комментарии повторно не проверяются.

## 3. Как проверить кампанию

Есть два разных способа.

### Проверить само сообщение

Внутри сохранённой кампании найдите «Проверить отправку»:

1. Укажите числовой ID своего личного профиля VK, не ID сообщества.
2. Нажмите «Отправить в VK».
3. Проверьте сообщение и вложение в личке.

Это настоящая отправка. Получатель должен разрешить сообщения сообщества.

Сначала сохраняйте изменения: тест отправляет **сохранённую версию** сообщения.

Такая проверка не требует комментария, не проверяет условия его отбора и не считается обычной выдачей промокода. Она помогает проверить содержание и возможность отправки, но не весь путь обработки комментария.

### Проверить весь путь от комментария

В разделе «Настройки»:

1. Включите «Реагировать только на тестовую фразу».
2. Укажите фразу, например `тестовое сообщение`.
3. Сохраните настройки.
4. Напишите новый комментарий под постом кампании, содержащий эту фразу.

Например:

```text
тестовое сообщение, хочу получить промокод
```

Другие комментарии в этом режиме будут пропускаться.

Остальные условия продолжают действовать: подписка, минимальная длина, стоп-слова и защита от повторной выдачи. Поэтому человек, уже получивший промокод этой кампании, может не получить его повторно. Для проверки самого сообщения в таком случае используйте «Проверить отправку».

**Перед запуском акции для покупателей выключите тестовый режим и сохраните настройки.** На личные диалоги этот режим не влияет.

## 4. Сценарии — диалог с клиентом

Сценарий — это цепочка ответов: что бот говорит сначала, чего ждёт от человека и что делает дальше.

Бот отвечает по настроенным правилам. Самостоятельно придумывать ответы, как нейросеть, он сейчас не умеет.

### Создать и редактировать сценарий

Откройте «Сценарии» → «Новый сценарий». Появится пример диалога.

- Нажмите на блок — справа откроются его настройки.
- Перетаскивайте блок за заголовок.
- Добавляйте нужные блоки кнопками над схемой.
- Чтобы соединить блоки, нажмите кружок справа у нужного выхода, затем кружок слева следующего блока. Следующий блок можно выбрать и в настройках справа.
- Чтобы переместить схему, перетаскивайте пустое место. Масштаб меняется кнопками «+» и «−».
- Для переключения между сохранёнными сценариями используйте список вверху страницы.

Редактировать большую схему удобнее с компьютера.

### Для чего нужны блоки

| Блок | Что делает |
| --- | --- |
| **Начало** | Определяет, с чего начинается диалог. |
| **Сообщение** | Отправляет текст, вложение и, при необходимости, кнопки. |
| **Вопрос** | Задаёт вопрос и ждёт ответ клиента. |
| **Условие** | Проверяет условие и направляет по ветке «Да» или «Нет». |
| **Промокод** | Отправляет предложение из выбранной кампании. |
| **Менеджер** | Передаёт общение человеку и приостанавливает ответы бота этому клиенту. |
| **Завершение** | Заканчивает цепочку; при необходимости отправляет заключительный текст. |

Сообщение без кнопок сразу переходит к следующему блоку. Сообщение с кнопками ждёт выбора клиента.

Блок «Условие» может проверить слова в последнем сообщении клиента, подписку на сообщество или то, получал ли клиент промокод выбранной кампании.

### Добавить кнопки

Откройте блок «Сообщение», добавьте кнопку и укажите:

1. Надпись — например «Открыть магазин».
2. Действие:
   - **«Открыть ссылку»** — укажите полный адрес сайта, начиная с `https://`;
   - **«Перейти к блоку»** — выберите следующий шаг.

Например, в приветствии можно сделать:

- «Магазин» — открывает сайт;
- «Получить промокод» — ведёт к блоку «Промокод»;
- «Позвать менеджера» — ведёт к блоку «Менеджер».

Под одним сообщением можно добавить до пяти кнопок. Кнопка со ссылкой только открывает сайт — сама по себе она не продолжает цепочку.

Для кнопки «Назад» выберите действие «Перейти к блоку» и укажите блок с предыдущим меню.

### Задать вопрос и использовать ответ

Например, добавьте блок «Вопрос»:

```text
Какой размер вас интересует?
```

В поле «Сохранить ответ как» укажите `size`.

В следующем сообщении можно написать:

```text
Вы выбрали размер {size}. Сейчас поможем с подбором!
```

Бот подставит ответ клиента. Название для сохранения ответа задавайте латинскими буквами без пробелов, например `size` или `city`. Используйте его в следующих сообщениях после того, как клиент ответил на вопрос.

Можно настроить разные продолжения по словам в ответе. Например, ответ содержит «доставка» — перейти к информации о доставке. Ветки проверяются сверху вниз; срабатывает первая подходящая. Для остальных ответов настройте «Другой ответ».

Для обращения по имени в сообщениях сценария можно использовать `{first_name}` или `{user_name}`.

### Выдать промокод в диалоге

Добавьте блок «Промокод» и выберите существующую активную кампанию.

Бот возьмёт её сообщение, код и вложение, проверит подписку и защиту от повторной выдачи. Фильтры длины комментария и стоп-слов к обычной переписке не применяются.

### Проверить и включить сценарий

- **«Проверить»** — найти ошибки в настройках и соединениях.
- **«Предпросмотр»** — пройти диалог прямо в панели, не отправляя сообщения в VK.
- **«Сохранить»** — сохранить черновик.
- **«Опубликовать»** — включить эту версию для клиентов.

**Сохранить и опубликовать — разные действия.** Изменения черновика не меняют работающий диалог до публикации.

В предпросмотре можно писать ответы, нажимать кнопки и переключать условие «Клиент подписан». «Начать заново» сбрасывает пробный диалог. Реальным клиентам и менеджеру ничего не отправляется. Вложения показываются по названию; фактическую отправку файлов проверяйте в VK.

Если проверка сообщает об ошибке, исправьте указанное место. Например, у кнопки может быть не выбран следующий блок, а у вопроса — не настроен переход для другого ответа.

Одновременно работает **один опубликованный сценарий**. Публикация другого переключает бота на него. Это не отключает кампании за комментарии.

Кнопка «Приостановить» выключает активный сценарий. Если ответы на личные сообщения включены, вместо него используется обычный ответ из раздела «Общение».

Для проверки в настоящем VK напишите со своего профиля в сообщения сообщества:

```text
меню
```

Эта команда начинает диалог заново. После публикации изменений используйте новое меню и новые кнопки: старые кнопки предыдущей версии больше не выполняют прежние действия.

## 5. Общение — ответы и менеджеры

В разделе «Общение» находятся общие настройки личной переписки.

**«Отвечать на личные сообщения»** включает или выключает ответы в чате. Выдачу промокодов за комментарии этот переключатель не отключает.

**«Ответ без активного сценария»** — обычный ответ, который используется, когда сценарий не опубликован или приостановлен.

Для подключения менеджеров заполните:

- **ID менеджеров VK** — числовые ID личных профилей сотрудников через запятую или с новой строки. Например: `123456789, 987654321`. Можно указать одного или нескольких менеджеров, до 50 человек. Повторяющиеся ID автоматически убираются.
- **Слова вызова менеджера** — например `оператор, менеджер, человек`.
- **Ответ при вызове менеджера** — например «Передал ваш вопрос менеджеру. Он ответит здесь».

Каждый менеджер должен разрешить сообщения от сообщества, чтобы получать уведомления, и иметь доступ к сообщениям сообщества, чтобы отвечать клиентам от его имени.

Клиент может вызвать менеджера, написав одно из заданных слов, либо нажав кнопку сценария, ведущую к блоку «Менеджер».

После вызова бот приостанавливает ответы этому клиенту и отправляет уведомление всем указанным менеджерам. **Сотрудник продолжает переписку в сообщениях сообщества VK, а не в админке бота и не со своего личного профиля.**

### Как закрепляется клиент

1. Всем менеджерам приходит уведомление с клиентом и кнопкой «Взять в работу».
2. Кто первым ответит клиенту от сообщества или нажмёт эту кнопку, становится ответственным за обращение.
3. Остальные получают уведомление, что обращение уже взял другой менеджер.
4. В разделе «Клиенты» появляется статус «В работе у менеджера» и ссылка на ответственного.

Даже при одновременном нажатии двух менеджеров обращение закрепится только за одним. Повторный ответ другого сотрудника не меняет ответственного.

Для автоматического закрепления по ответу в настройках VK откройте «Управление» → «Работа с API» → «Callback API» → «Типы событий» и включите **исходящие сообщения — `message_reply`**. Входящие сообщения `message_new` также должны оставаться включены. Если VK не передаёт боту, какой сотрудник написал ответ, используйте кнопку «Взять в работу» — она не зависит от определения автора исходящего сообщения.

Закрепление показывает ответственного в боте, но не отнимает у других сотрудников доступ к переписке VK. Перед ответом обращайте внимание на уведомление о том, кто взял клиента.

Ошибка доставки уведомления одному менеджеру не мешает отправке остальным. Подробности ошибки можно посмотреть в разделе «Клиенты».

Команда клиента `меню` или кнопка администратора «Вернуть к боту» закрывает текущее обращение и снимает закрепление. При следующем вызове менеджера уведомление снова получат все сотрудники. Старые кнопки «Взять в работу» после закрытия обращения не действуют.

Поле «ID тестового пользователя» задаёт получателя по умолчанию для проверки кампаний. Перед тестовой отправкой его можно изменить прямо в форме.

После изменений нажмите «Сохранить настройки».

## 6. Клиенты

Здесь отображаются известные боту клиенты: участники диалогов, авторы обработанных комментариев и получатели промокодов.

В таблице видны имя, фамилия, фото, ссылка на профиль VK, доступный телефон, дата последнего учтённого сообщения бота и статус рассылок. Поиск работает по имени, фамилии, телефону и числовому ID. Фильтр «Кому бот писал» оставляет только подтверждённых получателей.

Нажмите **«Обновить данные VK»**, чтобы бот запросил свежие данные профилей. Это выполняется в фоне, не мгновенно. Если вместо имени пока указан «Клиент 123…», дождитесь обновления. Ошибка получения профиля будет видна в его карточке.

**Телефон появится, только если VK его передаёт**, либо клиент сам оставил его в вопросе сценария с именем ответа `phone`, `telephone` или `телефон`. Даже если номер виден вам на странице VK, API может его не вернуть. Бот не раскрывает скрытые номера. Для обновления номера, полученного в сценарии, также нажмите «Обновить данные VK».

Кнопка **«Карточка»** показывает контакты, последние сохранённые входящие события и участие в рассылках. «Исключить из рассылок» отключает будущие массовые сообщения этому человеку, но не обычные ответы бота.

Чтобы написать только части клиентов, отметьте их галочками и нажмите **«Рассылка выбранным»**. Выбор сохраняется при переходе между страницами списка в этой вкладке браузера. Отписавшиеся, менеджеры и люди без подтверждённых исходящих сообщений будут исключены при подготовке.

### Диалоги и менеджеры

Вверху раздела «Клиенты» нажмите **«Диалоги и менеджеры»**. Здесь сохранён прежний список обращений.

Можно посмотреть:

- кто сейчас общается с ботом, кто ждёт менеджера, а кто уже закреплён за сотрудником;
- ID ответственного менеджера, ссылку на его профиль и время закрепления (UTC);
- сохранённые ответы на вопросы;
- последние входящие сообщения, действия «Взять в работу» и ответы настроенных менеджеров во время обращения;
- ошибки обработки.

Кнопка **«Вернуть к боту»** закрывает обращение, снимает закрепление за менеджером и разрешает боту продолжить работу со следующего сообщения клиента. Сама кнопка сообщение не отправляет. Для обновления списка и статусов нажмите «Обновить».

Клиент также может вернуться к боту, написав `меню`.

Это не полная переписка с возможностью отвечать: менеджер отвечает через VK. Получатель промокода без входящих сообщений будет в общей таблице клиентов, но не обязательно в списке диалогов. Результат обработки комментария смотрите в «Статистике».

Старые подтверждённые выдачи промокодов появятся в общей таблице автоматически. Если в прежней версии не сохранилось подтверждение приветствия или тестового сообщения, мы не можем уверенно восстановить такую отправку: будет отметка «Нет подтверждённой отправки». Само входящее сообщение не считается доказательством ответа бота. Новые успешные отправки уже учитываются.

## 6а. Рассылки

### Создать и проверить

1. Откройте **«Рассылки»**.
2. Напишите название для себя, например «Новая коллекция — октябрь». Клиент название не увидит.
3. Выберите **«Все, кому бот писал»** или **«Выбранные в разделе „Клиенты“»**.
4. Введите текст. Кнопки «Имя» и «Фамилия» вставят `{first_name}` и `{last_name}` — каждый увидит свои данные. Если имени ещё нет, бот обратится «друг». Промокод и ссылку для этой рассылки указывайте прямо в тексте, они не берутся из кампаний.
5. При необходимости прикрепите файл с компьютера: фото, видео, аудио, PDF, ZIP или текст до 50 МБ. Дождитесь надписи «Прикреплён». Видео и аудио отправляются как файлы.
6. Нажмите **«Предпросмотр и проверка»**. Появятся пример сообщения и точное число выбранных получателей. Пока никому ничего не отправлено.
7. Введите свой числовой ID VK и нажмите **«Отправить только тест»**. Это отправит сообщение только вам. У вас должно быть разрешение получать сообщения сообщества. Тест не запускает всю рассылку.

Пример текста:

```text
Привет, {first_name}!

В магазине появилась новая коллекция. Для тебя скидка по промокоду SARKISIAN10.
Загляни: https://sarkisianbrand.ru/
```

### Запустить и следить за результатом

Убедитесь, что клиенты согласились получать такие сообщения. Старая переписка и разрешение VK — не то же самое, что согласие на рекламную рассылку. Отметьте подтверждение согласия и нажмите **«Запустить рассылку»**.

Отправка идёт постепенно, а не всем в одну секунду. В истории видны количество отправленных сообщений, пропуски и ошибки. **«Журнал»** показывает результат по каждому получателю. «Доставлено VK» означает, что VK принял сообщение, но не обязательно что человек его прочитал.

- **Пауза** — остановить оставшуюся очередь. «Продолжить» возобновит её.
- **Отменить** — отменить оставшиеся отправки окончательно. Уже отправленные сообщения не удаляются.
- **Черновик** — сохранённая проверка, которая ещё не запущена. Её можно открыть через «Проверить и запустить» в истории или отменить.

В момент паузы или отмены уже начатая отправка может успеть завершиться. Очередь сохраняется при перезапуске сервера; незаконченная отправка после сбоя может ждать до 5 минут. Повторное нажатие запуска одного черновика не создаёт ещё одну очередь.

Текст, вложение и список получателей фиксируются при подготовке. Для правок закройте предпросмотр, исправьте форму и подготовьте новый черновик; старый при необходимости отмените. Люди, которые напишут боту позже, не добавятся в уже подготовленную рассылку.

### Кого бот пропустит

Отписавшихся, менеджеров, недоступные профили и людей без подтверждённого сообщения от бота. Разрешение VK проверяется непосредственно перед отправкой: если человек запретил сообщения, бот пропустит его. Не нужно обходить этот запрет.

Бот сам добавляет строку об отписке и кнопку **«Отписаться от рассылок»**. Клиент также может написать **«Стоп»**. Это работает даже при выключенном общении и во время разговора с менеджером. Обычные ответы на запросы и выдача подарка продолжают работать. Подписаться обратно может сам клиент, написав **«Подписаться на рассылку»**.

Если VK сообщил об ошибке ключа, ограничении отправки или капче, рассылка приостановится. Причина появится в истории. Сначала разберитесь с ограничением, затем продолжайте — многократно запускать её заново не нужно.

Для учёта запрета/разрешения сообщений рекомендуется включить в Callback API события **`message_allow`** и **`message_deny`**. Событие **`message_new`** обязательно для команды и кнопки отписки. Даже без событий разрешения бот всё равно проверит его перед отправкой. Новые обязательные переменные ENV для этой функции не нужны.

## 7. Статистика

Здесь показаны результаты обработки **комментариев к постам и видео**: сколько обработано, сколько промокодов отправлено и почему некоторые комментарии пропущены. В столбце «Публикация» видно, к чему относится комментарий, и есть ссылка на пост или видео.

Основные результаты:

- **«Отправлено»** — личное сообщение отправлено.
- **«Короткий комментарий»** — не выполнено условие длины.
- **«Стоп-слово»** — найдено запрещённое слово.
- **«Уже выдан»** — сработала защита от повторной выдачи.
- **«Нет подписки»** — человек не подписан.
- **«Тестовый фильтр»** — включён тестовый режим, но нужной фразы нет.
- **«Ошибка»** — отправка не удалась; подробности указаны рядом.
- **«Ждём получения в чате»** — подарок ожидает команды «Подарок» или «Начать»; это ещё не успешная выдача.
- **«Ждём подписку»** — человек запросил подарок; бот отправит его после подтверждённого вступления или проверки кнопкой.
- **«Нужно разрешение на сообщения»** — человек вступил, но запретил сообщения сообщества; нужно разрешить их и снова написать «Подарок».
- **«Приглашение уже создано»** — повторный комментарий не получил ещё один публичный ответ.
- **«Нельзя пригласить под видео»** — выбран режим приглашения, недоступный под самим видео с ключом сообщества.
- **«Акция недоступна»** — при получении подарка кампания уже выключена или удалена.
- **«Ошибка выдачи в чате»** — VK не принял личное сообщение; подарок не отмечен выданным, можно повторить запрос.

Это не общая статистика всех диалогов. Информацию о личном общении смотрите в разделе «Клиенты». Ручная тестовая отправка не увеличивает счётчик обычных выдач промокодов.

## 8. Если бот не отвечает

### Нет сообщения после комментария

Проверьте:

1. Кампания активна, а изменения сохранены.
2. Указан правильный ID поста либо поле оставлено пустым для общей кампании. Приостановленная отдельная кампания имеет приоритет над общей.
3. Комментарий новый, а не уже обработанный ранее.
4. Если включён тестовый режим, комментарий содержит тестовую фразу.
5. Комментарий подходит по длине и не содержит стоп-слов.
6. Клиент подписан и разрешил сообщения сообщества.
7. Клиент ещё не получал промокод этой кампании, если включена защита от повторов.

Причину пропуска или ошибку посмотрите в «Статистике».

В режиме приглашения подарок не приходит сразу после комментария: клиент должен перейти в чат и отправить «Подарок» или нажать «Начать». Обычная кнопка «Проверить отправку» в админке проверяет только личное сообщение, не создаёт комментарий-приглашение и по-прежнему требует разрешения получателя. Полный путь проверяйте новым комментарием в тестовом режиме.

Для видео дополнительно проверьте, что включено событие `video_comment_new`. Если комментарий к клипу вообще не появляется в статистике, сначала нужно выяснить, передаёт ли VK это событие боту; одни настройки кампании не могут заставить VK прислать событие.

### Нет ответа в личном чате

Проверьте переключатель «Отвечать на личные сообщения» в разделе «Общение» и публикацию сценария.

Возможно, клиент передан менеджеру — тогда напишите `меню` или нажмите «Вернуть к боту» в разделе «Клиенты».

Если сценарий не опубликован, используется «Ответ без активного сценария» из раздела «Общение».

### Не видны изменения диалога

После редактирования сценария нажмите «Опубликовать», затем начните новый диалог командой `меню`.

### Менеджер ответил, но клиент не закрепился

Убедитесь, что личный числовой ID этого менеджера указан в разделе «Общение», ответ отправлен от сообщества и в Callback API включено событие `message_reply`. Автоматическое закрепление работает только во время открытого обращения к менеджеру, а не для любой переписки.

Если VK не передал ID ответившего сотрудника, нажмите «Взять в работу» в уведомлении. Обновите раздел «Клиенты», чтобы увидеть ответственного.

### В предпросмотре работает, а в VK — нет

Предпросмотр работает без подключения к VK. Для реальных отправок сообщество должно быть подключено к боту: заполнены данные доступа, подтверждён сервер и включены события новых комментариев и личных сообщений.

Если подключение ещё не завершено, настройки в панели можно подготовить заранее, но настоящие сообщения пока отправляться не будут.

## 9. Короткий порядок запуска

### Акция за комментарии

1. Создайте действующий промокод в магазине.
2. Создайте кампанию для нужного поста или оставьте ID пустым для всех публикаций. Для видео включите `video_comment_new` в VK.
3. Заполните сообщение, прикрепите файл и настройте условия.
4. Сохраните кампанию и проверьте отправку на свой профиль.
5. Проверьте новый комментарий с тестовой фразой.
6. Выключите тестовый режим, сохраните настройки и оставьте кампанию активной.

### Диалог с клиентом

1. Включите ответы на личные сообщения в «Общение».
2. Укажите ID менеджеров через запятую и слова их вызова. Для автоматического закрепления по ответу включите в VK событие `message_reply`.
3. Создайте сценарий с сообщениями, кнопками и вопросами.
